## Files built or changed

- `src/geointel/change/postprocess.py`: deterministic 3 x 3 majority filter,
  followed by same-class connected-component MMU removal. Ties retain the
  center class if tied; otherwise the lowest class ID wins. Nodata centers stay
  nodata. Components below 0.5 ha become unclassified (0), not a neighboring
  class. Connectivity and threshold are configured.
- `src/geointel/change/ndvi_baseline.py`: T2-minus-T1 NDVI threshold baseline
  with jointly valid pixel accounting and a distinct nodata code.
- `src/geointel/change/association.py`: 1 km fishnet change-mask aggregation,
  Spearman rank correlation, global Moran's I with seeded permutation
  significance, analytical Getis-Ord Gi* scores, positive top-N hotspot ranking,
  and a stratified mapped-area adjustment helper that requires reference labels.
  Gi* p-values use a one-sided analytical normal approximation; this convention
  is included in each generated result.
- `scripts/run_phase45_colab.py`: consumes the hosted T1/T2 composite COGs,
  prints runtime/provider/scene IDs when upstream metadata is supplied, creates
  Phase 4 rule-map candidate strata and an empty label template, processes
  Phase 5 outputs, and writes spatial association products, metadata JSON, and
  a manifest. Optional accuracy requires a completed labels CSV; area adjustment
  additionally requires an explicit probability-sample assertion and labeller.
- `scripts/validate_external.py`: optional raster alignment and overlap checks
  with GHSL, Hansen GFC, and ESA WorldCover. Its output labels these as external
  consistency checks, not accuracy results.
- `config/config.yaml`, `docs/definitions.md`, `docs/methods.md`: connectivity,
  permutation count, MMU behavior, and 30 m terrain/aspect resampling convention.
- `tests/test_phase5_change.py`: synthetic fixtures only; no downloaded raster
  or real AOI composite is read.

## Hosted run

Run the approved-AOI T1/T2 composite workflow first. The AOI approval requires
regenerating the composites for the approved square. Then in the hosted repo
checkout (Python 3.11):

```bash
python scripts/run_phase45_colab.py \
  --config config/config.yaml \
  --t1-composite /content/drive/MyDrive/geo-intel-run/cogs/t1_composite.tif \
  --t2-composite /content/drive/MyDrive/geo-intel-run/cogs/t2_composite.tif \
  --run-metadata /content/drive/MyDrive/geo-intel-run/metadata.json \
  --output-dir /content/drive/MyDrive/geo-intel-run/phase45
```

Colab users must mount Drive and replace the paths with their actual run folder.
On successful execution the command writes T1/T2 postprocessed class rasters,
NDVI difference and decline rasters, urban-expansion and vegetation-loss masks,
the clipped 1 km association grid GeoPackage, `phase45_metadata.json`, and
`run_manifest.json`. It does not run during repository preparation.

Optional labeled evaluation and area adjustment, after manual labels exist:

```bash
python scripts/run_phase45_colab.py ... \
  --labels /content/drive/MyDrive/geo-intel-run/labels/labels.csv \
  --labeller annotator_A \
  --area-labeler annotator_A \
  --probability-sample
```

The probability-sample flag is an explicit assertion by the analyst, not a
property inferred from a CSV. A valid area adjustment also requires samples in
every mapped-class stratum. No label or estimate is generated by the default
run.

**GHSL epoch caveat:** the project windows are T1 2018–19 and T2 2024–25, whereas these GHSL layers are E2020 and E2025. Neither is an exact epoch match; E2025 is projected. Treat both only as approximate, coarse-resolution consistency context.

The approved AOI bounds used for tile selection are **77.9126819°E–78.2322535°E**
and **30.1464523°N–30.4237957°N** (EPSG:4326). Hansen's 10° grid labels a tile
by its top-left corner; therefore the containing 70–80°E, 30–40°N tile is
`40N_070E`. WorldCover labels each 3° tile by its lower-left corner, so this
AOI intersects the 75–78°E and 78–81°E tiles in the 30–33°N band.

GHSL product files and the two 100 m epochs are listed in the [European
Commission GHSL catalogue](https://human-settlement.emergency.copernicus.eu/ghs_buS2023.php)
and its [official data archive](https://jeodpp.jrc.ec.europa.eu/ftp/jrc-opendata/GHSL/GHS_BUILT_S_GLOBE_R2023A/).
Hansen's [official download page](https://storage.googleapis.com/earthenginepartners-hansen/GFC-2025-v1.13/download.html)
defines 10 x 10 degree granules by top-left corner; the AOI bounds therefore select
`40N_070E` (north edge of its containing 30–40°N row, west edge of 70–80°E column).
ESA's [WorldCover data
page](https://esa-worldcover.org/en/data-access) documents its 3 x 3 degree COG
tiles and the [2021 v200 Zenodo record](https://zenodo.org/records/7254221)
identifies the N30E060 macro archive if acquiring through Zenodo; extract only
the two listed map tiles from that large package.

## Limitations and manual actions

- Rerun composites on the approved AOI before Phase 4–5 processing.
- Review candidate points and independently interpret labels in QGIS. Do not use
  candidate-map class values as reference truth.
- Review output seams, coverage, and alignment before interpreting changes.
- NDVI differences can reflect phenology, residual atmospheric effects, or
  reflectance harmonization issues. No causal conclusion follows from association.
- 100 m GHSL and 30 m Hansen cannot confirm 10 m class labels. WorldCover 2021
  is a one-year external context layer, not a same-epoch reference for either
  composite.
- Gi* hotspot p-values are analytical normal approximations. Report this method
  alongside the scores; do not present them as a field-validated significance test.
- Area-adjusted estimates are only defensible when labels follow the intended
  probability design, mapped-class strata are known, and every nonempty stratum
  has reference samples.
