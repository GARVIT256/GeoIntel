# Data report

This report is generated by `notebooks/colab_run.ipynb` after a successful hosted-runtime run. It is intentionally left without scene IDs or measurements until that run produces them. Do not fill fields from cached inventories, prior reports, or estimates.

The approved AOI is `config/aoi_dehradun_30km_approved.geojson`. Rerun the Colab smoke test and full T1/T2 composites against this AOI before populating this report. Run the notebook from top to bottom in a Python 3.11 Colab or Kaggle session. The final cell reads the exported composite COGs and run metadata, computes the fields below, creates `valid_pixel_map.png`, and writes this file from those outputs.
