## Reflectance offset diagnostic

Earth Search uses the item property `earthsearch:boa_offset_applied`; its [issue discussion](https://github.com/Element84/earth-search/issues/24) describes the field, and [issue #66](https://github.com/Element84/earth-search/issues/66) records a false flag that appeared inconsistent with pixels. The user supplied targeted raw-DN checks for Earth Search Sentinel-2 COGs carrying both flag values and `raster:bands.offset=-0.1`; based on that evidence, code suppresses this specific -0.1 for items containing the Earth Search property, regardless of its boolean value. This provider-specific exception does not change generic STAC offsets. If a PB4+ item acquired on or after 2022-01-25 has a zero/missing offset and does not have the explicit true flag, the fallback remains -0.1; pre-2022 acquisitions reprocessed under PB05 do not get this fallback. Earth Search's [Sentinel-2 collection documentation](https://github.com/Element84/earth-search#gainoffset-in-items-after-jan-25-2022) and the [STAC Raster Extension](https://github.com/stac-extensions/raster) describe scale/offset conversion, with offset applied after scale. This code rule is based on user-supplied diagnostics and has not been independently revalidated in this workspace; hosted item-pair check: **NOT YET RUN**.

Code-path assessment: current code suppresses a declared -0.1 for Earth Search Sentinel-2 items identified by the namespaced property (true or false), to avoid applying a second correction to the COG pixels described in the supplied targeted checks. It honors declared offsets for other assets and uses the PB4+ post-2022 fallback for zero/missing offsets when the flag is false or absent. Pre-2022 PB05 reprocessed scenes do not get the fallback. This is a code-level rule only; same-tile 2018-12-01 baseline 00.01 vs 05.00 B04/B08/B11 window means and differences: **NOT YET RUN**. No additional reflectance means or offsets are inferred here.

For Planetary Computer items, the Earth Search-specific property may be absent. Generic STAC offsets continue to be honored. When the flag is absent and the offset is zero/missing, PB4+ items acquired on or after 2022-01-25 use the -0.1 fallback; pre-2022 PB05 reprocessed acquisitions do not. [ESA's Sentinel-2 processing documentation](https://sentiwiki.copernicus.eu/web/s2-processing) describes the PB4 L2A BOA offset and reflectance equation. A live lookup of one Planetary Computer item found no `raster:bands` field on B04; this is an item-level observation only: [STAC item JSON](https://planetarycomputer.microsoft.com/api/stac/v1/collections/sentinel-2-l2a/items/S2A_MSIL2A_20241209T053221_R105_T43RGP_20241209T082353). No raster results were generated in this workspace.
